Preguntas rápidas

Antes de escribirme, quizás esto te ordena un poco.

¿Puedo empezar aunque todavía no tenga todo el texto?

Sí. Podemos partir de una idea, ordenar el mensaje y después pulir los textos durante el proceso.

¿La web queda lista para celular?

Sí. El diseño responsive es parte del trabajo, no un extra agregado al final.

¿Se puede conectar WhatsApp o Instagram?

Sí. Podemos dejar llamadas a la acción visibles para que la consulta llegue por el canal que uses más.

¿Después se pueden sumar más secciones?

Sí. La idea es construir una base ordenada para que después puedas crecer sin rehacer todo.
